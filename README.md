## 수정 방법

`index.html` 맨 아래 `<script>` 안의 `CONFIG` 값만 바꾸면 사이트 전체에 반영됩니다.

```js
var CONFIG = {
  TEL: "01068570716",   // 전화 상담 번호
  KAKAO_URL: "",        // 카카오 채널 주소 (비워두면 카톡 버튼이 전화 연결로 동작)
  FORM_KEY: "..."       // web3forms 키 (상담 신청 메일 수신)
};
```

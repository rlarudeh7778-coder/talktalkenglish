# 톡톡 일대일 원어민 영어회화 (TALK TALK)

하루 20분, 말하기 중심으로 진행하는 성인 1:1 원어민 영어회화 — 랜딩페이지.

- `index.html` : 단일 파일 랜딩페이지 (아이콘 전부 인라인 SVG)
- `travel.mp4` / `travel-poster.jpg` : 영상 밴드 배경 (1280x720, 무음, 화면에 가까워질 때만 지연 로딩)
- 배포 : GitHub Pages — https://rlarudeh7778-coder.github.io/talktalkenglish/
- 상담 : 카카오톡 오픈채팅 / 전화 010-6857-0716

## 수정 방법

`index.html` 맨 아래 `<script>` 안의 `CONFIG` 값만 바꾸면 사이트 전체(우측 고정 버튼, 모바일 하단바, 상담 카드)에 반영됩니다.

```js
var CONFIG = {
  TEL: "01068570716",                              // 전화 상담 번호
  KAKAO_URL: "https://open.kakao.com/o/sit5FnKi"   // 카카오톡 오픈채팅 주소
};
```
